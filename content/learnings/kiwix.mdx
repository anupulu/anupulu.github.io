Contributing to Kiwix, an open-source project that makes Wikipedia and other educational content available offline, first as a volunteer and now as a part-time Product Manager. The project reaches millions of users without reliable internet access.

## Key Features

- **Kiwix Hotspot Device**: Leading product development for offline knowledge distribution
- **Open Source Platform**: Making Wikipedia and educational content available offline
- **Global Reach**: Serving communities with limited internet access worldwide

## Key Learnings

1. **Product Leadership**: Balancing user needs with technical constraints in product development
2. **Global Impact**: Open source contributions can reach millions of users worldwide
3. **Digital Inclusion**: Technical solutions can bridge significant digital divides
4. **Community Power**: Collaborative development drives meaningful change

## Impact & Next Steps

The project demonstrates how technology can serve public good while maintaining accessibility. We're currently focusing on:

- Enhancing the Kiwix Hotspot device for broader deployment
- Expanding content libraries for offline access
- Strengthening community engagement and contributions
